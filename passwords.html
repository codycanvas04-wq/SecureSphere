🌟 The 4 Golden Rules

📏

1. Make it long

Longer passwords generally give attackers more possibilities to guess. Consider a long passphrase.

🧩

2. Make it unique

Use a different password for every account. Reusing one password can put multiple accounts at risk.

🎲

3. Avoid predictable details

Names, birthdays, favourite teams, and simple patterns can make a password easier to guess.

🗝️

4. Store it safely

A reputable password manager can generate and store unique passwords so you don't need to memorise all of them.

🕵️ Weak vs. Strong: Learn the Difference

❌ A predictable example

Example: password123

Why avoid it? It uses a common word followed by a familiar number pattern. Attackers can try common combinations.

✅ A better approach

Create a long, unique passphrase from unrelated words, or use a password manager to generate a random password.

The important thing is that it is hard to predict and isn't reused on other accounts.

💡 Remember: symbols aren't magic!

Replacing a letter with a symbol or adding "123" doesn't automatically make a password secure. Length, uniqueness, and unpredictability matter too.

🛡️ Extra Layers of Protection

📱

Two-factor authentication

Turn on two-factor authentication (2FA) when available. It adds another step to verifying your identity.

🚨

Never share verification codes

Never give an unexpected caller or message your one-time password (OTP) or sign-in verification code.

🔄

Respond to suspected exposure

If a password may have been exposed, change it promptly on the affected service and anywhere it was reused.
